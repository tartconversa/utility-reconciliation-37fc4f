# 资料口径

全部主体和观测均为本地合成资料，不代表企业、个人或真实设备。编号只在资料包内有意义，金额为人民币元，时刻统一为带 +08:00 的北京时间。空单元表示未知或不适用，不等于零；真假值用 true/false；数值不含千位分隔。CSV 行顺序不表示业务先后。时间区间采用左闭右开，除非字段说明另有规定。

蒸汽压力节点 HP、MP、LP，source/to 是流向，电量千瓦时、汽量吨、能量兆焦。读数是区间总量，半开区间。绝对误差 bound 与读数同单位，不是标准差。可信测量不得任意修改，未计量边有容量范围但无已知流量。平衡允许明确登记的损失，不允许隐含平衡插件。 retrofit 记录实际改造状态，proposal 是待评审组合；热量需求和产量为可比服务量。价格是区间单价，碳因子为外部研究假设。
edges 的容量单位为等效8小时汽吨；4小时分表需按实际区间覆盖与总表对齐，bound 对该条观测本身生效。service_t 为生产服务规模不是管网汽需求，lp_user 为真实供汽观测。power 中购电与设备电耗是8小时区间总电量；购煤为同区间吨。hp_mp 的背压系数见 power，设备消耗不能凭空变成LP供汽。外购电可补发电不足，价格及排放为线性计量，供汽缺口不可用购电替代。初始观测不保证彼此可行，应用需要区分误差和真正冲突。
M2、M4 的4小时 value 是实际4小时总量，不能再次乘除两个来凑平衡。HP 出口经背压后到MP，mp_vent 为MP放空；waste_mp 是同区间外部回收量。锅炉煤耗与蒸汽的历史关系由 power 和 measurements 共同提供，不提供预定节煤模型。
lp_loss 是有物理依据的未计量低压损失，容量为等效8小时0至12吨；不是为每期自动平衡而预填的实际损耗。

## edges
公用工程连接与业务容量。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| edge_id | string | 连接 |
| source | string | 上游 |
| target | string | 下游 |
| kind | string | 类型 |
| lower | number | 最小流量 |
| upper | number | 最大流量 |
| conversion | number | 输出输入比 |

记录键：edge_id。

## meter_specs
仪表绝对误差界与采样时长。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| meter_id | string | 仪表 |
| edge_id | string | 对应流量 |
| unit | string | 单位 |
| bound | number | 绝对误差界 |
| interval_h | integer | 采样小时 |

记录键：meter_id。

## measurements
多采样间隔观测，未强制凑成平衡。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| reading_id | string | 读数 |
| meter_id | string | 仪表 |
| start | datetime | 区间开始 |
| hours | integer | 时长 |
| value | number | 观测量 |
| available_at | datetime | 可知时刻 |

记录键：reading_id。

## operations
生产服务量、余热及改造状态。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| day | date | 日期 |
| load | number | 装置负荷 |
| service_t | number | 产品服务量 |
| waste_t | number | 可回收汽量 |
| retrofit | boolean | 实际汽改电 |
| maintenance | boolean | 检修 |
| available_at | datetime | 可知时刻 |

记录键：day。

## power
电力边界和煤耗，backpressure_kwh_t 按通过背压机的汽量计。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| day | date | 日期 |
| import_kwh | number | 购电 |
| coal_t | number | 购煤 |
| backpressure_kwh_t | number | 背压发电系数 |
| device_kwh | number | 设备电耗 |

记录键：day。

## proposals
业务方案与设备作用假设；收益尚未计算。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| proposal_id | string | 方案 |
| compressor_count | integer | 改造设备数 |
| steam_reduction_t | number | 设备侧减汽 |
| electric_add_kwh | number | 设备侧增电 |
| recovery_change_t | number | 余热可回收变化 |

记录键：proposal_id。

## external
购能价格、排放因子和服务价值约定。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| scenario | string | 外部假设 |
| power_yuan_kwh | number | 电价 |
| coal_yuan_t | number | 煤价 |
| power_kg_kwh | number | 购电排放 |
| coal_kg_t | number | 煤排放 |

记录键：scenario。

| edge_id | string | 连接 |
| day | date | 日期 |
| value | number | 吨 |

| available_at | datetime | 可知时刻 |
